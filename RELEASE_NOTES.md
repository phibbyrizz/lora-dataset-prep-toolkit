# v0.1.4

Initial public release of the Windows-first LoRA Dataset Prep Toolkit.

Highlights:
- Read-only processing of curated source folders.
- Conservative YuNet face crops.
- JoyCaption captions with identity-LoRA-focused instructions.
- Folder-derived triggers with interactive override in single-dataset mode.
- Conservative caption consistency cleanup and hard image/caption validation.
- Training-ready ZIP plus validation and diagnostic reports.
- Windows setup/preflight with CUDA GPU checks and verified YuNet acquisition.

The separate image-search Dataset Collector is intentionally not included because its original authorship/license has not been established with enough confidence for redistribution.
